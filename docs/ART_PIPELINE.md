# Художественная замена ресурсов Noriwake

## Указания владельца

- Не рисовать игровую графику кодом/Canvas/SVG-примитивами вместо изображений.
- Для новых иллюстраций использовать качественные сгенерированные изображения
  либо проверенные лицензированные ресурсы.
- Если начинается генерация: одна партия из **10 отдельных изображений**,
  затем остановка для проверки владельцем. Не делать следующую партию без него.
- Не заменять хорошие рабочие ресурсы только ради количества изменений.
- Не ухудшать качество, механику и читаемость ради формальной смены оформления.

Текущая техническая итерация новых изображений не требовала: сгенерировано 0.
Новые программно нарисованные иллюстрации не добавлялись. Canvas-макет из первой
итерации оставлен как исторический прототип, а не направление production-графики.

## Что сохраняем до проверки

Оригинальные 3D-модели, скелеты/анимации, коллизии и материалы Zooshi пока нужны
для проверки нативной сборки. Нельзя заменить анимированного 3D-клиента плоским
портретом и назвать это равноценным улучшением. Лицензия кода Apache не означает
автоматической проверки каждого стороннего ассета; происхождение учитываем отдельно.

## Первая возможная партия: 10 самостоятельных ассетов (ещё не создана)

1. Фон главного меню: плавучая кухня в неоновом ночном порту, 16:9.
2. Фон загрузки: кухня-лодка в пути, спокойная композиция, 16:9.
3. Портрет Тётушки Ко, капибары у причала, 1:1.
4. Портрет Рикса, енота-механика, 1:1.
5. Портрет Пипа, маленькой рисоварки-помощника, 1:1.
6. Портрет Мадам Люмы, цапли в ночном клубе, 1:1.
7. Иллюстрация главы «Первые огни», старый причал, 16:9.
8. Иллюстрация главы «Ночной рынок», 16:9.
9. Иллюстрация следующей главы, верхние каналы города, 16:9.
10. Коллекционный фонарь «Первый огонь», одиночный предмет, 1:1.

Единый стиль: качественная стилизованная 3D-иллюстрация, тёплый свет кухни,
бирюзовый/коралловый неон, дружелюбные персонажи, ясный силуэт. Без чужих
логотипов, текстов в изображении и имитации конкретного художника/франшизы.
Текст/кнопки остаются обычным интерфейсом, не запекаются в картинку.

Портреты предназначены для диалогов/коллекции, не вместо 3D-моделей внутри реки.
Экраны истории не считаются готовыми игровыми районами.

## После генерации и одобрения

Для каждого изображения записать prompt, происхождение, дату, назначение,
исходный файл, экспорт и статус одобрения. Не заявлять юридическую уникальность
генерации и не считать её проверкой товарного знака.

Разрешенная техническая обработка: ресайз, кроп, сжатие, конверсия PNG/WebP,
подготовка размеров/прозрачности. Это обработка изображения, а не программное
рисование новых персонажей. Проверять результат визуально, не только по размеру.
Сначала внедрить в соответствующий экран, проверить читаемость на телефоне и
расход памяти, сохранить возможность отката. Не затирать чужие уведомления.
