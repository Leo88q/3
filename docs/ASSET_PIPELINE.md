# Сборка оригинальных ресурсов Zooshi / Noriwake

## Подтверждено локально, 2026-10-12

Собран **настоящий набор ресурсов**, без замены FBX-моделей, анимаций или
изображений процедурными заглушками. Это **не APK и не проверка игры на Seeker**.

| Тип | Файлов |
|---|---:|
| Модели `.fplmesh` (FBX и исходные JSON) | 45 |
| Анимации `.motiveanim` | 57 |
| Материалы `.fplmat` | 62 |
| Текстуры WebP | 71 |
| Звуковые файлы OGG | 103 |
| Шрифты TTF | 2 |
| Таблицы переносов HYB | 33 |
| Бинарная схема сущностей BFBS | 1 |
| Графы поведения | 14 |
| Траектории | 4 |
| Всего, включая конфигурации, схемы, шейдеры и notices | **553** |

Manifest — дополнительный файл, в число 553 не входит. Исходный сезонный overlay
сохранён как upstream-ресурс, а не как новый готовый контент Noriwake.
Все 71 WebP полностью декодированы закреплённой библиотекой движка
`webp@8af2771813632e2007988c8df6ad7e68b28ad121`, а не только новой Pillow.
Проверка GPU-загрузки, blending, визуального качества на телефоне ещё впереди.

## Воспроизведение

Нужны Linux x86_64 (включая WSL2), Python 3.10+, C/C++ compiler, make,
GitHub CLI с доступом к API. FBX-конвертеры — проверенные исходным Git blob ID
статически слинкованные Linux ELF из закреплённых FPLBase/Motive, не LFS pointers.
Не требуется скачивать или переупаковывать сторонний FBX SDK для этого рецепта.

Из корня репозитория:

```sh
python3 -m venv .cache/native-venv
. .cache/native-venv/bin/activate
python3 -m pip install cmake==3.31.6 ninja==1.11.1.4 -r tools/requirements-native-assets.txt
python3 tools/build_native_assets.py --fetch
python3 tools/build_native_assets.py --check

# Отдельная проверка совместимости текстур со старым decoder:
python3 tools/native.py deps --only webp  # если ещё не подготовлен
python3 tools/check_native_webp.py
```

`--fetch` скачивает только недостающие исходные ресурсы и девять зависимостей
asset-рецепта; уже существующие неизвестные изменения не перезаписывает.
Pillow устанавливается явно, не внутри Gradle. При раздельно установленных
инструментах доступны `--cmake /absolute/path` и `--ninja /absolute/path`.
Полный Android-билд требует также остальные native-зависимости и SDK/NDK.

Результат: `native/zooshi/built_assets/`, включая `noriwake-build-manifest.json`.
Файлы сборки, host-инструменты и загрузки игнорируются Git. На чистой машине их
нужно воспроизвести. Для проверки готового набора `--check` не требует Pillow,
CMake, загрузок или повторного запуска конвертеров.

## Что исправлено

- Точные commit исторических freetype/ogg/vorbis/webp/harfbuzz/hyphenation
  найдены в GitHub-зеркалах. URL происхождения и SHA остались неизменными в lock.
  Каждый скачанный файл проверяется по исходному Git blob ID. `export-ignore`
  больше не теряет файлы: отсутствующий в архиве blob берётся через API и
  также проверяется; неверные байты блокируют публикацию зависимости.
- Порт Scene Lab builder на Python 3 без distutils, с проверенным Pillow
  resize/WebP путём. Правила размера текстур и качество из исходного рецепта
  сохранены; JPEG/PNG/TGA исходники не меняются. Pillow 11.3.0 использует свой
  WebP encoder; байтовая идентичность древнему cwebp не обещается.
- Старый flatc собран из закреплённых исходников с небольшими документированными
  GCC-поправками. Debug выбран намеренно; исходные `-Werror` не отключены.
  Это не подтверждение Release-сборки всей старой библиотеки.
- Каждая полная сборка использует чистые промежуточные/выходные директории.
  Только после успеха заменяется предыдущий набор. Удалённые материалы или
  изменения metadata не маскируются устаревшими промежуточными PNG.
- К конвертированным ресурсам добавлены исходные audio, fonts, shaders, notices
  и все 33 HYB из upstream FlatUI recipe. Gradle читает только полный набор,
  проверяет input/output hashes и останавливается при отсутствии/изменении данных.

## Лицензии и границы

Оригинальные copyright и Apache LICENSE сохранены. Модификации Scene Lab и
FlatBuffers хранятся как проверяемые overlays с исходными blob IDs, а не только
в скачанной папке. Лицензии каждой группы hyphenation копируются в
`hyphen-data/licenses/`; notices шрифтов идут вместе со шрифтами. Pillow —
только host-инструмент, в Android-приложение не включается.

Сохранение notices не заменяет финальный аудит распространения: остаются
проверка всех assets/fonts/dependencies, связанных host FBX-tools, товарных
знаков и иконок перед публикацией. Никакого вывода о полной юридической
готовности релиза эта сборка не делает.

Локально подготовлены 24 из 25 прямых pinned зависимостей; Cardboard отключён
и не нужен touch-профилю. Два вложенных gitlink Gumbo (тестовые данные и gtest)
не загружены. Полный C++/NDK linkage, Gradle, APK, Android lifecycle,
производительность, MWA/cNFT и новая сюжетная часть здесь не проверялись.
CI-рецепт добавлен, но удалённый запуск CI в этой сессии не выполнялся.


### Исправление следующей итерации

Прежние 552 файла не включали `flatbufferschemas/components.bfbs`: его создавал
только старый NDK asset recipe в другой директории. Это не косметический файл —
его читает `World` и фабрика сущностей. Теперь BFBS генерируется закреплённым
flatc в staging вместе с остальными ресурсами, итог — **553** файла.
`check_native_cpp.py` проверяет его настоящим FlatBuffers verifier, root type
`fpl.EntityListDef`/identifier `ENTI`, и отбрасывание повреждения/обрезанного файла.
NDK больше не конвертирует и не копирует assets поверх проверенного набора,
не удаляет его при clean, а вызывает тот же `--check`. Эти makefile-изменения
пока проверены статически; запуск настоящего ndk-build остаётся необходимым.
