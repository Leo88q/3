## Текущий прототип

Оригинальная реализация на JavaScript/Canvas. Ни исходники, ни изображения, ни
музыка, ни персонажи google/zooshi не скопированы. Сходство жанра и механики
не означает включение Apache-кода. Не следует утверждать, что эта сборка —
официальный продукт Google, Solana или Metaplex.

Векторная графика находится в src/main.js, звуки синтезируются Web Audio.
Внешние шрифты, CDN, изображения и аналитические SDK не используются.
Название Noriwake — рабочее, юридическая проверка уникальности не выполнена.
Проект не получает открытую лицензию автоматически из-за использования
Apache/MIT-зависимостей. Лицензию на оригинальную часть выбирает владелец.

## Проверка Zooshi (2026-10-12)

GitHub API репозитория https://github.com/google/zooshi сообщил archived=true,
license=Apache-2.0, default_branch=master. README перечисляет старые библиотеки
Fun Propulsion Labs и требует рекурсивного клонирования submodules.
Проверены метаданные и README, а НЕ полное дерево лицензий/ресурсов и НЕ сборка.

Если позже переносить код:
1. Зафиксировать upstream commit и список заимствованных файлов.
2. Сохранить исходные copyright/attribution и копию Apache 2.0.
3. Сохранить применимые уведомления NOTICE, если они есть.
4. Пометить измененные исходные файлы.
5. Проверить отдельно каждую зависимость и каждый ассет: лицензия репозитория
   не гарантирует одинаковую лицензию всех вложенных ресурсов.
6. Исключить чужой брендинг из собственной айдентики.

Сейчас Apache-лицензия Zooshi не включена в приложение, потому что его материалы
не распространяются в этом проекте. Это не юридическое заключение.

## Реальные зависимости

Capacitor — MIT; Vite и инструменты сборки имеют собственные лицензии.
`npm run licenses` собирает полные доступные LICENSE/NOTICE из установленных
npm-пакетов в public/THIRD_PARTY_NOTICES.txt, включаемый в веб-сборку и APK.
Файл содержит и инструменты разработки: это консервативный расширенный список,
а не точный перечень кода внутри финального бандла.

Android использует AndroidX, Cordova и Gradle, у которых есть отдельные лицензии.
В public/ANDROID_NOTICES.txt находится предварительный список и Apache 2.0.
Перед публичным релизом обязателен аудит разрешенного Gradle dependency graph,
включая транзитивные зависимости и применимые NOTICE. Он здесь НЕ завершен:
Android SDK/Gradle-сборка в этой среде не запускались. Не публиковать APK до этой
проверки. npm-список не заменяет аудит нативных зависимостей.

## Offline-итерация

Удаление Firebase/GPG не удаляет авторские уведомления из переработанных
исходников. Полные исходные заголовки сохранены, происхождение проверяется
`tools/native.py verify`, а новые изменения отражены в modifications.json.
Сам факт удаления прямой SDK-зависимости не разрешает преждевременно убирать
лицензии остальных библиотек из итоговой поставки — потребуется проверка
реально разрешенного dependency graph и APK после миграции.

Графические модели/текстуры этой итерацией не заменялись. Новые изображения
не генерировались. Порядок художественной замены зафиксирован в ART_PIPELINE.md.

## FPLBase overrides и современные build tools

Переработанные FPLActivity.java и два Makefile из зафиксированного FPLBase
поставляются в native/overrides/fplbase вместе с полной лицензией Apache 2.0.
Исходные copyright-заголовки и заметки о прошлых изменениях сохранены,
добавлены prominent Noriwake modification notices. Пины/хеши —
native/dependency-overrides.json. Gradle wrapper взят из уже существующего
Android template; provenance замен зафиксирована в MODIFICATIONS.md.

Android API jar и Eclipse JDT jar для проверки Java находятся только в
игнорируемом cache и не включены в приложение/исходный пакет. Их источники
и идентификаторы зафиксированы в tools/check_android_java.py и ANDROID_PORT.md.
Перед релизом по-прежнему требуется аудит фактического APK и всего дерева
нативных библиотек: успешная проверка исходников не заменяет этот аудит.
