# Что значит «полноценная готовая игра»

Не считать импорт исходников или существование APK доказательством готовности.
Каждый этап ниже требует проверяемого результата.

## 1. Воспроизводимая нативная сборка — В РАБОТЕ
- [x] Перенести исходную игру, графы, схемы, ссылки на ресурсы и лицензии.
- [x] Зафиксировать upstream commit и прямые dependency gitlinks.
- [x] Восстанавливать тяжелые ресурсы с проверкой Git blob ID.
- [x] Добавить изолированно тестируемые нативные правила короткого рейса.
- [ ] Разрешить полное рекурсивное дерево зависимостей и проверить лицензии.
- [x] Удалить прямую Firebase/GPG интеграцию и сетевую рекламу из исходников/конфигураций; скомпилировать offline-провайдеры.
- [x] Отключить запуск VR/NFC в Activity (touch-управление).
- [x] Удалить VR SDK из Java/NDK source path FPLBase, скомпилировать все Java-файлы без VR JAR.
- [x] Подготовить конфигурацию AGP/Gradle/NDK, libc++ и 64-битных ABI.
- [ ] Проверить полную NDK-компиляцию/линковку offline-игры.
- [ ] Завершить перенос и проверить JNI, все C++ зависимости и pipeline ресурсов на поддерживаемых инструментах.
- [ ] Собрать arm64 debug APK; установить и запустить на реальном устройстве.
- [ ] Проверить страницы памяти/нативные библиотеки по требованиям целевых Android.

## 2. Полный игровой цикл — НЕ ПРИНЯТ
Унаследованы как код: движение по реке, физика и прицеливание, животные,
анимации, попадания, квоты/круги, рост сложности, музыка, меню, пауза, XP,
выбор/разблокировка суши и уровней. Всё это нужно проверить запуском.

Добавлены как непроверенные в движке интеграции: короткий рейс, Classic toggle,
HUD, локальная статистика, текстовые вехи истории.

Для приемки: обучение без внешней инструкции, 10 последовательных рейсов,
пауза/сворачивание/возврат, отсутствие потери прогресса, работа без сети,
корректный звук, удобное управление на Seeker, измеренные FPS и нагрев.

## 3. Собственная игра Noriwake — НЕ ГОТОВО
- [ ] Проверить название и убрать оригинальный брендинг со всех графических экранов.
- [ ] Своя лодка, неоновые районы, персонажи, окружение и визуальные эффекты.
- [ ] Русская локализация с лицензированными шрифтами.
- [ ] Комбо/горячая волна в нативной физике, косметический инвентарь, ежедневные задания.
- [ ] Полный сюжетный прогресс: текстовые вехи сейчас не заменяют новые игровые районы.
- [ ] Настройки доступности, баланс и полноценный QA.

## 4. Solana — НЕ НАЧАТО
MWA native bridge, гостевой аккаунт, подтверждение владения кошельком,
backend-проверка результатов, одна devnet cNFT-награда, retry/idempotency,
защита от ботов, лимиты расходов, мониторинг, метаданные, восстановление
после отмены/таймаута. Серверные ключи никогда не попадают в APK.

Mainnet только после отдельного подтверждения владельца и расходов.
Кошелек не нужен для базовой игры. Никакого собственного токена и обещаний дохода.

## 5. Публикация — ЗАБЛОКИРОВАНА
Релизный ключ владельца, окончательный app ID, полный third-party license bundle,
политика данных, проверка требований dApp Store, тест подписанного APK,
оформление publisher и подтверждение публикации владельцем.

PvP/кланы/турниры с призами — отдельная сетевая система после базового релиза,
не возможность, которую дает один лишь форк Zooshi.
