# Noriwake · первый играбельный прототип

Ночная кухня на воде: 90 секунд, доставка еды жителям причалов, комбо и косметика.
Рабочее название, не проверенный товарный знак. Самостоятельная реализация,
не форк Zooshi; исходники и ресурсы Google не включены.

## Быстро попробовать

Требуется Node.js 22 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173). С телефона в одной сети
используйте сетевой IP компьютера. В Arena используйте Live Preview.

Нажмите «Отправиться в рейс», затем тапайте по животным с белым значком суши.
Промах или пропущенный клиент обнуляет серию. Каждые 10 последовательных
попаданий включают 8 секунд двойных очков. За 100 очков начисляется одна
единица чаевых. После завершения рейса чаевые можно потратить в «Моя лодка».
Пауза — кнопка Ⅱ или Escape; при скрытии вкладки игра ставится на паузу.
Прерванный рейс не дает награду. Звук по умолчанию выключен.

Прогресс локальный (localStorage). Очистка данных браузера/приложения удаляет его.
Нет аккаунта, облачного восстановления, кошелька, NFT и денежных операций.
Клиентские очки можно подделать: этот прототип не подходит для призовых турниров.

## Проверка и production web

```sh
npm test
npm run build
npm run preview
```

`dist/` — статическая сборка. Все игровые ресурсы локальны, внешних API нет.
Для веб-версии первая загрузка требует сети; PWA/offline cache не реализован.
В APK веб-ресурсы упакованы локально.

## Android APK

Android-оболочка Capacitor уже находится в `android/`.
Нужны Android Studio, JDK 21, Android SDK Platform 35 и совместимые Build Tools.
Первое разрешение Gradle/Maven зависимостей требует доступа к их репозиториям.

```sh
npm ci
npm run android:sync
npm run android:open
```

В Android Studio дождитесь Gradle Sync, запустите на устройстве или используйте
Build → Build App Bundle(s) / APK(s) → Build APK(s) (название меню зависит от версии).
Из терминала Linux/macOS:

```sh
cd android
chmod +x gradlew
./gradlew assembleDebug
```

На Windows: `gradlew.bat assembleDebug`.
Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.
Это тестовый APK, а не подписанный издательский релиз. Android-сборка и Seeker
в текущей среде НЕ проверены: установленных SDK и доступа ко всем Maven-хостам нет.

Для релиза: выбрать окончательный applicationId (сейчас com.noriwake.game),
заменить стандартную иконку, провести аудит лицензий нативных зависимостей,
создать собственный release keystore локально и собрать signed APK.
Ключи, пароли, seed-фразы не коммитить и не отправлять в чат.
Требования Solana dApp Store нужно проверить непосредственно перед публикацией.

## Файлы

- `src/game.js` — счет, награды, косметика и валидация локальных данных.
- `src/main.js` — интерфейс, Canvas, управление и звуки.
- `tests/game.test.js` — тесты игровой модели.
- `docs/LICENSING.md` — происхождение и границы лицензионной проверки.
- `docs/ROADMAP.md` — следующий этап и критерии готовности.
- `public/THIRD_PARTY_NOTICES.txt` — npm-лицензии; обновляется при сборке.
- `public/ANDROID_NOTICES.txt` — предварительные Android-уведомления.

## Перед выдачей реальных наград

Нужны Kotlin/JNI или Capacitor native plugin для MWA, backend с проверкой
результатов, безопасная привязка гостя к кошельку и идемпотентная очередь
выдачи. Ключ минтера хранить только на сервере. Ничего из этого прототип не
имитирует. Не считать клиентский рекорд доказательством права на NFT.

### Браузерные тесты

```sh
npx playwright install chromium
npm run test:e2e
```

На Linux могут понадобиться системные библиотеки браузера (`npx playwright install --with-deps chromium`).
Можно указать уже установленный Chromium через `CHROMIUM_PATH`.
Проверено в среде разработки: 5 unit-тестов, 2 браузерных сценария (полный рейс,
пауза, сохранение результата, покупка косметики, мобильная ширина 390 px),
production web build и `cap sync android`. Это не заменяет проверку нативного APK.
